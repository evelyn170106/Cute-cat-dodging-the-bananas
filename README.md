# Cute cat dodging the Bananas 🐱🍌

A simple arcade game built in Java (Processing) for COMP1000 at Macquarie University.

## How to play
- Use the LEFT and RIGHT arrow keys to move the cat
- Dodge the falling bananas – each banana that hits the ground earns 1 point
- Touching a banana ends the game

## Features
- Keyboard controls and collision detection
- Score tracking and game-over screen
- Custom shapes drawn with bezier curves

## Run it
Download Processing (processing.org), open the .pde file and press Run.
